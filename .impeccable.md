## Design Context

### Users
Immortal Coil is built for the project creator first, then for modders who want to extend a branching narrative graph. Users are editing story structure, control nodes, conditions, and script output while keeping hot-reload-friendly Common Lisp workflows.

### Brand Personality
The interface should feel monochrome, haunted, precise, and tool-like. It should share the game's black-and-white CRT mood without becoming decorative or obscuring the editor's job.

### Aesthetic Direction
Use a stark black-and-white visual language with subtle phosphor bloom, scanline texture, and crisp graph geometry. Avoid colorful SaaS dashboards, soft rounded admin panels, purple/blue gradients, and generic card-heavy layouts.

### Design Principles
- Keep the narrative graph as the first-viewport focus.
- Make structure legible before making it ornamental.
- Prefer dense, direct controls that modders can scan quickly.
- Preserve the Lisp script format as the source of truth.
- Keep visuals monochrome and consistent with the game.
