#+title: JRPG Adventure

* Status

Implemented as the largest current branch spine.

* Entry

The matchbook path leads into a straight-faced fantasy adventure. It should read
at first as a bog-standard JRPG demon-lord quest: inn, village, companion,
overworld, slime, tower, demon lord.

* Author truth

- The familiar genre frame is useful because later details can pull certainty
  away.
- It can be corny and stereotypical early, but should not wink too hard.
- The demon-lord route is one built-in spine, not the canonical endpoint for
  all JRPG play.
- Hidden long-term idea: the demon lord may turn out to be the player from
  another path. Do not foreshadow this in the early route.
- Stats, route choices, companion choice, combat results, inventory, and
  village errands should live in the shared store for later hooks and mods.

* Minigames

** Overworld

Kind: =:jrpg-overworld=

Current behavior:

- WASD/arrows movement.
- Small map with village, bridge, sign, tower, grass.
- Reaching grass advances to the road mile marker.
- Movement stores route/landmark facts.

Expansion direction:

- Larger Oakbarrow-to-tower map.
- More landmarks: shrine, pond, roadside camp, old bridge, toll hut.
- More walking is now viable because the path has ambience and short cues.

** Turn combat

Kind: =:jrpg-combat=

Current behavior:

- 2x2 menu: =ATTACK=, =MAGIC=, =ITEM=, =RUN=.
- Uses JRPG state for HP/MP/gold/potions/xp.
- Victory, defeat, and retreat set =jrpg-last-battle=.

Expansion direction:

- Add more enemies.
- Add companion effects.
- Add a separate battle cue only if it does not become too rhythmic.
