* Immortal Coil

Common Lisp / Claylib narrative-game prototype.

** Run

#+begin_src sh
sbcl --eval '(require :asdf)' \
     --eval '(asdf:load-system :immortal-coil)' \
     --eval '(immortal-coil:main)'
#+end_src

** Build

#+begin_src sh
nix build .#immortal-coil
#+end_src

The binary is in:

#+begin_src sh
./result/bin/immortal-coil
#+end_src

** Release Bundles

GitHub Actions has an on-demand workflow:

#+begin_src text
Actions -> Bundled builds -> Run workflow
#+end_src

It uploads:

#+begin_src text
immortal-coil-linux-x86_64.zip
immortal-coil-windows-x86_64.zip
#+end_src

Linux:

#+begin_src sh
./run-immortal-coil.sh
#+end_src

Windows:

#+begin_src bat
run-immortal-coil.bat
#+end_src

** In-Game Editor

#+begin_src sh
sbcl --eval '(require :asdf)' \
     --eval '(asdf:load-system :immortal-coil)' \
     --eval '(immortal-coil:main)'
#+end_src

Use the title menu: =MODS=, then =EDIT BASE GAME=, =CREATE MOD=, or =EDIT MOD=.

Useful editor bindings:

#+begin_src text
C-h      show bindings
C-y      rename current node / edit node details
C-l      edit node destinations
C-e      edit current node text
C-i      insert a node at the current link
C-r      replace the current node
C-g      cancel active editor panel
#+end_src

** Options

The title menu and pause menu have an OPTIONS screen.

Options are saved to:

#+begin_src text
save/options.lisp
#+end_src

** Gameplay

#+begin_src text
J       open the journal
Escape  pause
#+end_src

** Saves

The title menu =LOAD GAME= list supports:

#+begin_src text
RET     load selected save
D/DEL   request delete, press again to confirm
Escape  cancel/back
#+end_src

With =IMMORTAL_COIL_SAVE_DIR= set, options are saved to:

#+begin_src text
$IMMORTAL_COIL_SAVE_DIR/options.lisp
#+end_src

** Mods

Public mod API:

#+begin_src text
docs/mod-api.md
#+end_src

Narrative notes:

#+begin_src text
docs/narrative.md
#+end_src

Bundled dialogue is loaded from:

#+begin_src sh
game/manifest.lisp
#+end_src

Player mods should use:

#+begin_src text
mods/<mod-id>/manifest.lisp
mods/<mod-id>/assets/
#+end_src

Minimal manifest:

#+begin_src lisp
(:id "example-mod"
 :name "Example Mod"
 :depends-on ("immortal-coil/base")
 :scripts ("story.lisp")
 :assets "assets/")
#+end_src

Total conversion manifests can also set:

#+begin_src lisp
(:title-logo "logo/title-logo.png"
 :start "example-mod/start")
#+end_src

Player mods are loaded from:

#+begin_src sh
mods/
#+end_src

Extra mod directories:

#+begin_src sh
IMMORTAL_COIL_MOD_DIR=/path/to/mods sbcl ...
#+end_src

Disable mods:

#+begin_src sh
IMMORTAL_COIL_DISABLE_MODS=1 sbcl ...
#+end_src

The title menu =MODS= -> =MOD LIST= toggles individual mods. Disabled
directory mods get:

#+begin_src text
mods/<mod-id>/.disabled
#+end_src

Legacy single-file mods get a sidecar marker, such as
=mods/.example.disabled= for =mods/example.lisp=.
