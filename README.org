* Immortal Coil

Common Lisp / Claylib narrative-game prototype.

** Run

#+begin_src sh
sbcl --eval '(require :asdf)' \
     --eval '(asdf:load-system :immortal-coil)' \
     --eval '(immortal-coil:main)'
#+end_src

** Build

#+begin_src sh
nix build .#immortal-coil
#+end_src

The binary is in:

#+begin_src sh
./result/bin/immortal-coil
#+end_src

** Level Editor

#+begin_src sh
nix run .#editor
#+end_src

Open:

#+begin_src text
http://127.0.0.1:8080/tools/dialog-editor/
#+end_src

Direct Nimble run:

#+begin_src sh
cd tools/dialog-editor
nimble run immortal_coil_editor --root ../..
#+end_src

Port or bind address:

#+begin_src sh
nix run .#editor -- --host 0.0.0.0 --port 8081
#+end_src

** Load Check

#+begin_src sh
ASDF_OUTPUT_TRANSLATIONS=/root/common-lisp/immortal-coil/:/tmp/immortal-coil-fasl/ \
  sbcl --noinform --non-interactive \
    --eval '(require :asdf)' \
    --eval '(asdf:load-system :immortal-coil)'
#+end_src

** Mods

Bundled dialogue is loaded from:

#+begin_src sh
game/manifest.lisp
#+end_src

Player mods should use:

#+begin_src text
mods/<mod-id>/manifest.lisp
mods/<mod-id>/assets/
#+end_src

Player mods are loaded from:

#+begin_src sh
mods/
#+end_src

Extra mod directories:

#+begin_src sh
IMMORTAL_COIL_MOD_DIR=/path/to/mods sbcl ...
#+end_src

Disable mods:

#+begin_src sh
IMMORTAL_COIL_DISABLE_MODS=1 sbcl ...
#+end_src
